# 公開ツール

## 共通構造

公開ツールは `src/app/(main)` に page、`src/components` に UI、`src/lib` または `src/class` に再利用可能なロジックを置きます。メイン導線へ載せる機能は `src/lib/json/features.json` に登録します。

| 機能 | 主なロジック | データ |
|---|---|---|
| しりとり | `src/class/ShiritoriManager.ts` | ユーザー入力 |
| サイコロ | `src/components/diceComponent` | `dice-nets.tsx` の展開図定義 |
| アルファベット変換 | `alphabet-converter.tsx` | クライアント状態 |
| 都道府県検索 | `prefecture-search-table.tsx` | コンポーネント内定義 |
| 方眼紙 | `src/components/graphpaper/grid-model.ts` | クライアント状態 |
| 辞書検索 | `src/class/SearchManager.ts` | `public/dic/*.dic` |
| 星座検索 | `src/lib/constellation` | `constellations-data.json` |
| 文字拾い検索 | `src/lib/character-pick-search.ts` | `SearchManager` の辞書 |

## 辞書基盤

`SearchManager` の `DICTIONARIES` が辞書一覧の正本です。

| key | type | ファイル |
|---|---|---|
| `buta` | `jp` | `public/dic/buta.dic` |
| `cefr` | `en` | `public/dic/CEFR-J.dic` |

辞書はブラウザから同一 origin で取得し、`SearchManager` がプロセス内で cache します。辞書検索、Shift Search、文字拾い検索がこの基盤を共有します。通常のアナグラム結果上限は `ANAGRAM_RESULT_MAXCOUNT=200` です。

## しりとり

入力を行単位の単語へ分け、空行と行の前後の空白を除いてから、`ShiritoriManager` が最長連鎖と未使用語を求めます。manager は static state を持つため、入力を設定してから結果を取得します。

画面は五十音表・入力欄・生成ボタンだけの1列構成です。結果は生成時にダイアログで表示し、閉じると入力画面へ戻ります。

- 五十音表は常時表示し、縦5段・横10列、右端の「あいうえお」から左へ並べます。や行・わ行の空欄も維持します。
- 灰色の立体キーに左上の五十音順番号・右下の使用数を表示し、使用済み文字を紫色で強調します。スマートフォンでも全10列を収め、表示切替は設けません。
- キーを押すと入力位置へ文字を挿入します。表からの入力では入力欄へフォーカスを移しません。
- 入力は1行1単語、最大2,000文字。文字数だけを表示し、空入力では生成できません。
- 結果は最長連鎖と未使用語をまとめて表示します。ダイアログを閉じると生成ボタンへフォーカスを戻します。

## サイコロ

`dice-nets.tsx` の展開図候補と、Three.js 系ライブラリによる 3D 表示を組み合わせます。各面の文字と回転は画面 state です。

## 方眼紙

Excel に近い操作の 1 マス 1 文字グリッドです（最大 20×20）。セルの値・塗り色・範囲操作・クリップボード変換は `grid-model.ts` の純粋関数、選択状態・履歴・入力イベントは `graph-paper-component.tsx`、ツールバーは `graph-paper-toolbar.tsx` が担当します。

- 入力は選択中セルに重ねた 1 つの `<input>` で受け、IME の確定文字列を右方向へ 1 文字ずつ展開します。`#`/`＃` は黒マスとして描画します。
- 範囲選択は Shift + 矢印・ドラッグ・行列見出し、Ctrl/⌘ + 矢印は入力済みブロックの端へジャンプします。
- コピーはタブ区切りテキストで書き出し、画面内のコピー内容と一致する貼り付けは塗り色も復元します。切り取り後の貼り付けは移動として元範囲を空にします。
- 塗りつぶしは Alt/Option + 0〜4 またはツールバー。元に戻す・やり直しは画面内の履歴（100 件）です。
- 行数・列数の欄は打ち途中の値をグリッドへ反映せず、フォーカスを外すか Enter で確定します（Esc で取り消し、整数でなければ元の値に戻す。元に戻す等で値が変わったら打ちかけの値は捨てる）。縮めて消えたマスは元に戻すで復元できます。
- 「空白を＃埋め」は状態を別に持たず、空マスがなく＃が1つ以上あるときにオンと表示します。オンで空マスを＃で埋め、オフで＃を消します。どちらも履歴に1件積みます。
- タッチはタップで選択し、「範囲選択」オン時だけなぞり選択のためにスクロールを止めます。
- 「範囲選択」トグルとタッチ向けの操作説明は、画面幅ではなく入力手段で出し分けます（タッチ入力がある端末で表示し、キーボード向けの説明はマウス等がある端末で表示）。タブレットでもなぞり選択が使えます。

## 星座検索

星座名、ラテン名・略称、季節・十二星座タブを横断します。かな正規化と検索判定は `src/lib/constellation/search.ts`、表示整形は `ConstellationSearchTable.tsx` が担当します。

## 文字拾い検索

最大 10 個の登録語から、各語ごとに指定した文字数範囲で文字を取り出し、構成可能な辞書語を返します。

- 既定は各登録語から 1 文字ずつ使う。
- 最小値 0 は、その登録語を使わない組み合わせを許す。
- 候補語の文字順は問わず、アナグラムを含む。
- 全組み合わせを生成せず、辞書語を走査して文字割り当て可能性を判定する。
- 結果上限は `CHARACTER_PICK_RESULT_MAXCOUNT=200`。
- 登録語の追加、削除、文字幅、辞書変更で結果を再計算する。

## 変更時の整合点

- 公開導線へ追加する page は `features.json`、JSON-LD index、sitemap への影響を同時に確認する。
- 辞書定義を変える場合は、辞書検索、Shift Search、文字拾い検索を確認する。
- text-like input はモバイル 16px 以上にする。
